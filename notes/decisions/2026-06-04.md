## 15:30 — 10GbE networking: switched to OM4 fiber + SFP+ direct; ONT consolidation rejected

**Files:** `notes/checklists/homelab-phase-7-10gbe-networking.md`, `notes/checklists/homelab-phase-2-nas-build.md`

**Research sources (archived in case links go dead):**
- https://forum.fibra.click/d/38533-ftth-unidata-sostituire-ont-esterno-con-ont-sfp — Unidata-specific thread confirming ONT SFP replacement is possible but requires full router replacement
- https://forum.fibra.click/d/27574-faq-guida-ottenere-25-gbps-su-singolo-dispositivo-con-ftth — Authoritative Italian FTTH/GPON guide (fibra.click community)
- https://hack-gpon.github.io — GPON stick compatibility database and ONT configuration reference

**Decision 1 — OM4 fiber + SFP+ direct, not Cat6A + 10GBASE-T:**
Switched the entire Phase 7 cabling approach. Reasons:
- 10GBASE-T transceivers (S+RJ10) draw 2-4W each inside the CRS305's fanless chassis. Three units in a sealed low-volume case is a thermal problem.
- SFP+ direct over OM4 is cheaper overall: saves ~€150-200 (no Cat6A reel, no shielded keystones, no termination tools, no hot transceivers) despite adding SFP+ NICs and 10G-SR modules.
- OM4 fiber is 2-3mm vs 7-8mm for Cat6A S/FTP — significantly easier to pull through conduit across multiple rooms.
- No shielded termination, no grounding, no punchdown or crimping tools required. Pre-terminated cables from FS.com plug directly into LC keystone adapters.
- Future-proofing: same OM4 fiber supports 25G/40G/100G with a transceiver swap. Cat6A is hard-capped at 10G.
- NIC change: AQC113 (RJ45) replaced by Mellanox ConnectX-3 MCX311A-XCAT (SFP+, ~€20 used). `mlx4` driver mainline since Linux 3.x — zero setup on Debian. Intel X520-DA1 is equivalent alternative (`ixgbe` driver).
- NAS co-location bonus: if NAS sits on the same shelf as the switch, a 1m DAC cable (~€10) replaces fiber + transceivers entirely for that link.

**Decision 2 — ONT consolidation rejected: keep CIG G-97CP external ONT + Fritz!Box 5530:**
Unidata provides a CIG G-97CP external ONT (separate box, ethernet out → Fritz!Box WAN port). Consolidation path would require:
1. Replacing the Fritz!Box entirely — the Fritz!Box 5530's SFP cage uses a proprietary AVM module that is NOT a standard GPON SFP stick. The PON MAC logic runs on the Fritz!Box mainboard. Third-party GPON sticks cannot authenticate through it.
2. Buying a MikroTik RB5009UG+S+IN (~€180-200) with real SFP+ HSGMII support + a GPON SFP stick (ODI DFP-34X-C2C or Technicolor AFM0003, ~€30-60) + cloning the GPON serial number from the CIG G-97CP.
3. Buying a separate WiFi AP (~€60-100) to replace Fritz!Box WiFi; losing DECT.
4. Net additional cost: ~€250 above keeping current setup.

From the fibra.click forum: Unidata likely uses a Huawei OLT (informed inference — they supplied Fritz!Box 5530s which only work on Huawei OLTs). The Fritz!Box 5530 GPON stick (AVM proprietary, "SFP GPON w/o PON MAC") has been appearing on OLT vendor blacklists as of 2025-2026. A confirmed Unidata user (xTheDoctah, forum thread above) successfully replaced their CIG ONT with an SFP stick via the Hack-GPON Telegram group — but this required knowing the OLT vendor, cloning the GPON serial, and accepting the risk of PLOAM password ban on misconfiguration.

**Conclusion:** The CIG G-97CP is a silent 1-2W box. Not worth €250 + complexity to eliminate it now. Revisit if Unidata upgrades the line to XGS-PON (10G service) — at that point an RB5009 or similar with a 10G SFP+ cage earns back the cost immediately by giving direct 10G WAN termination without a separate ONT.

## 14:00 — NAS motherboard selected: CWWK i5-8265UES 8-Bay + ConnectX-3 NIC

**Files:** `prompts/NAS-motherboard.prompt.md`, `notes/checklists/homelab-phase-2-nas-build.md`, `notes/shopping-list.md`  
**Decision:** Selected CWWK i5-8265UES 8-Bay board ($154.93) + Mellanox ConnectX-3 MCX311A-XCAT SFP+ NIC (~€20 used) as the NAS motherboard. Total ~€165-170 DDP. Reasons: only board evaluated that meets all hard requirements natively (8 SATA, dual M.2, dual-channel DDR4). Onboard 10GbE not required — PCIe add-in is acceptable (confirmed by user). Existing 16GB DDR4 kit from Wyse 5070 reused at zero cost. NIC changed from AQC113 RJ45 to ConnectX-3 SFP+ following 10GbE networking decision (see 15:30 entry) — fiber path requires SFP+ NIC, not RJ45. `mlx4` driver in mainline Linux kernel. Boards 2 (6 SATA, no 10GbE), 3 (zero native SATA, QC concerns), 4 (single-channel DDR5), and Jonsbo N3 board (no specs, no reviews) were all rejected.
